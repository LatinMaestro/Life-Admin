# iOS Roadmap

This document began when native iOS was deferred. The mobile-first web workflows and household backend are now sufficiently established for native delivery, and the approved plan now covers both iOS and Android.

The active cross-platform plan is `docs/MOBILE_APP_STORE_ROADMAP.md`.

## Current iOS Direction

- Expo/React Native and Expo Router.
- Genuine native screens rather than a WebView wrapper.
- Clerk Expo authentication with secure token storage.
- Versioned household APIs shared with Android.
- Core workflow parity before platform-specific enhancements.
- TestFlight before App Store submission.

## iOS Capabilities Still Requiring Separate Approval

- Push notifications
- Widgets
- Share sheet intake
- Camera/document capture
- Siri and App Intents
- Offline writes and background sync

## Release Constraints

The iOS app must provide adequate native utility, reviewer access, privacy policy access, account deletion where required, correct third-party login options, fictional screenshot data, and complete backend availability during review.
